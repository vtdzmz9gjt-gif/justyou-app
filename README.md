# Just You

A space for reconnecting with your authentic self — live at [justyou.fyi](https://justyou.fyi).

Not an optimization app. An emotional journey through five stages: Mystery → Safety → Recognition → Courage → Return. See the product spec for the full constitution, tone, and design language.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router) + TypeScript, deployed on Vercel
- Fraunces (serif, content) + Inter (sans, UI chrome) via `next/font/google`
- No accounts yet — state lives in the browser (see `src/lib`)

## Status

Phase 1: static design-system shell (Threshold → Home → Session → Trail navigation, no AI wired up yet).
